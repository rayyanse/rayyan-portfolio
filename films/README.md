# Project films

Walkthrough films played by the "Watch demo" / "Watch how it works" buttons on the project cards.

- **Source:** generated by Rayyan's film pipeline at `F:\SEO agent\portfolio-films` (not in this repo): one `films/<name>/film.html` per film, rendered frame by frame with Playwright (`render.py`), narrated with edge-tts (`make_vo.py`), mixed with music and sound effects (`mix.py`).
- **Real recordings:** `humanlabs.mp4` and `zephra.mp4` are real screen recordings of the live sites (`capture.py`). The rest are motion graphics built from each project's code or card; names and numbers in them are sample data and labelled as such on screen.
- **Encoding:** 1920x1080, H.264 (`-crf 26 -preset slow`), AAC 128 kbps, `+faststart` so playback starts before the whole file downloads. Posters (`<name>.jpg`) are single frames at 1280 px.
- **To replace a film:** re-render it in the pipeline, re-encode with the settings above, and overwrite `<name>.mp4` and `<name>.jpg` here.
